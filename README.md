# Claude 用量小工具

放在電腦桌面上的小女巫藥水瓶，瓶子裡的藥水就是你 Claude 訂閱方案「還剩多少額度」，用得越多藥水越少，一眼就能看到還能用多少。**Windows 和 Mac 都能用。**

## ⬇️ 下載最新版

- 💻 **Windows**：[點這裡下載（ClaudeUsageWidget.zip）](../../releases/latest/download/ClaudeUsageWidget.zip)　下載後解壓縮，雙擊 **「一鍵啟動.bat」**。詳細步驟看下面的〈Windows 版〉。
- 🍎 **Mac**：[點這裡下載（ClaudeUsageWidget-mac.zip）](../../releases/latest/download/ClaudeUsageWidget-mac.zip)　下載後解壓縮，對 `mac` 資料夾裡的 **「一鍵啟動.command」** 按右鍵 →「打開」。詳細步驟看下面的〈Mac 版〉。

## 這個程式能做什麼

Windows 版和 Mac 版的功能完全一樣：

- **即時顯示剩餘額度**：顯示 Claude 的「5 小時額度」和「每週額度」各還剩幾 %，每 60 秒自動更新一次。
- **重置時間倒數**：瓶子裡會顯示 5 小時額度什麼時候重置、還剩多久（例如「02:13 重置 · 還有2小時20分」）。
- **液面動畫**：剩得越少，瓶子裡的藥水越少；額度減少時會浮出「-5%」之類的提示，額度重置時顯示「重置!」。
- **哭哭模式**：額度用完（剩 0%）時，小女巫會換成哭臉，愛心碎掉、星星垂下、眼淚一顆顆掉下來；額度恢復後自動變回笑臉。
- **驚嚇模式**：5 小時或每週用量只要有增加，小女巫會嚇一跳：彈起來發抖、張大嘴巴，冒出「!!」對話框、汗滴和驚嚇線，藥水也跟著晃動；約 8 秒後換成閉眼鬆一口氣的安心表情，吐出一團白煙、旁邊冒出黃色強調線，再變回笑臉（額度用完時以哭哭模式為主）。
- **害怕模式**：5 小時或每週額度剩 10% 以下時，小女巫會露出有點害怕的表情，一直微微發抖，旁邊出現「!!!」對話框、發抖波浪線和冷汗；額度回到 10% 以上就恢復笑臉（剩 0% 時改由哭哭模式接手）。
- **常駐桌面最上層**：透明背景、沒有視窗外框，不會佔用 Windows 的工作列或 Mac 的 Dock。
- **變化紀錄**：每次用量變動都會記下時間與數字（只保留最近 30 天），可以用 Excel 或 Numbers 開啟查看。
- **可調整**：拖曳移動位置、滾輪（Mac 觸控板上下滑動）縮放大小、雙擊切換主顯示「5 小時」或「每週」。位置與大小會自動記住。
- **不會重複開啟**：已經開著時再開一次，不會多開一個，而是把原本的小女巫叫到最前面。

## 共通：你需要準備

- **Claude 帳號**（Pro、Max 等訂閱方案，在 claude.ai 的「設定 → 用量」頁面看得到百分比的帳號）
- **網路連線**（第一次安裝需要下載約 300 MB 的元件）
- 不需要系統管理員權限。

## 💻 Windows 版

### 使用前準備

- **Windows 10 或 Windows 11** 電腦。
- 不需要自己安裝 Python：沒有的話，「一鍵啟動.bat」會用 Windows 內建的 winget 自動安裝。

### 怎麼開始使用

1. 點最上方的「**Windows**」下載連結，下載 `ClaudeUsageWidget.zip`。
2. 在下載的檔案上按右鍵 →「**解壓縮全部**」，選一個固定的位置放（例如 `D:\Tools\`）。
   ⚠️ 之後不要再搬動這個資料夾，搬動後捷徑會失效（見下方常見問題）。
3. 打開解壓縮後的 `ClaudeUsageWidget` 資料夾，雙擊「**一鍵啟動.bat**」。
   - 如果跳出藍色的「Windows 已保護您的電腦」，按「**其他資訊**」→「**仍要執行**」。
4. 黑色視窗會開始自動安裝，約 3–5 分鐘，**請不要關閉它**。
5. 安裝完成時會問「要讓小工具開機時自動啟動嗎？」，要的話按鍵盤 **Y**，不要按 **N**。
6. 小工具出現在桌面後，會同時跳出 **Claude 登入視窗**：
   - 輸入 Email，按「使用 Email 繼續」。
   - 到信箱打開 Claude 寄來的登入信，**在登入連結上按右鍵 → 複製連結網址**，貼到登入視窗最上方的網址列（說明文字下面那一格），按 Enter。
   - 看到用量頁面後，直接關閉登入視窗即可。
7. 幾秒後瓶子裡就會顯示你的用量。以後直接點桌面上的「**Claude 用量小工具**」捷徑開啟。

### 操作方式

| 動作 | 功能 |
|---|---|
| 左鍵拖曳 | 移動位置 |
| 滑鼠滾輪 | 放大／縮小 |
| 雙擊 | 切換主顯示「5 小時」或「每週」（哭哭模式以主顯示的數字為準） |
| 滑鼠停在小工具上 | 顯示最後更新時間或錯誤提示 |
| 右鍵 | 選單：調整大小、切換顯示、立即更新、顯示登入網頁、開啟變化紀錄、離開 |

### Windows 常見問題

**Q：出現「Windows 已保護您的電腦」或防毒軟體警告？**
這是因為 `.bat` 檔沒有數位簽章，Windows 對所有從網路下載的批次檔都會這樣提醒。按「其他資訊」→「仍要執行」即可。

**Q：我搬動了資料夾，捷徑打不開？**
刪掉資料夾裡的 `.venv` 資料夾，刪掉桌面上的舊捷徑，再雙擊一次「一鍵啟動.bat」重新安裝即可。

**Q：桌面捷徑不見了，或圖示不是女巫？**
雙擊資料夾裡的「建立桌面捷徑.bat」重新建立。圖示沒有馬上更新時，在桌面按 F5 重新整理。

**Q：程式打不開，也沒有任何訊息？**
打開 `%USERPROFILE%\.claude_usage_widget\error.log` 查看錯誤內容。也可以刪掉 `.venv` 資料夾，再雙擊「一鍵啟動.bat」重新安裝。

**Q：自動安裝 Python 失敗？**
到 [python.org](https://www.python.org/downloads/) 下載 Python 3.12 安裝，安裝時**勾選「Add python.exe to PATH」**，再雙擊一次「一鍵啟動.bat」。

**Q：怎麼取消開機自動啟動？**
按 `Win + R`，輸入 `shell:startup` 按 Enter，刪掉裡面的「Claude 用量小工具」捷徑。

**Q：怎麼完全移除？**
1. 對小工具按右鍵 →「離開」。
2. 刪掉整個 `ClaudeUsageWidget` 資料夾。
3. 刪掉桌面與 `shell:startup` 裡的「Claude 用量小工具」捷徑。
4. 刪掉 `%USERPROFILE%\.claude_usage_widget` 資料夾（登入狀態與紀錄）。

## 🍎 Mac 版

### 使用前準備

- **macOS 11（Big Sur）以上**的 Mac，Intel 晶片和 M 系列晶片都可以。
- 不用自己安裝任何東西：第一次開啟時會自動下載需要的元件（包含 Python），全程不用另外找、不用另外點。

### 怎麼開始使用

1. 點最上方的「**Mac**」下載連結，下載 `ClaudeUsageWidget-mac.zip`。
2. 在「下載項目」資料夾裡雙擊 ZIP 檔解壓縮（Safari 可能已經自動解開），把解開的 `ClaudeUsageWidget-mac` 資料夾拖到一個固定的位置（例如「文件」）。
   ⚠️ 之後不要再搬動這個資料夾，搬動後「登入時自動開啟」會失效（見下方常見問題）。
3. 打開資料夾裡的 `mac` 資料夾，對「**一鍵啟動.command**」**按右鍵**（或按住 Control 再點一下）→「**打開**」→ 再按一次「**打開**」。
   - 如果只看到「完成」或「丟到垃圾桶」、沒有「打開」可以按：先按「完成」，到「**系統設定 → 隱私權與安全性**」，往下捲找到「已阻擋一鍵啟動.command」，按「**強制打開**」（或「仍要打開」），再輸入開機密碼。
4. 會跳出一個「終端機」視窗，自動下載並安裝需要的東西，約 3–5 分鐘，**請不要關閉它**。看到「小女巫已開啟」後就可以關掉終端機視窗。
5. 小女巫出現在桌面後，會跳出 **Claude 登入視窗**，登入方式和 Windows 版第 6 步一樣：用 Email 登入，把登入信裡的連結複製後貼到登入視窗最上方的網址列，按 Enter；看到用量頁面後關閉登入視窗。
6. 接著會問「要讓小女巫在每次登入 Mac 時自動開啟嗎？」，要的話按「**要**」。
7. 以後要開啟時，雙擊 `mac` 資料夾裡的「一鍵啟動.command」就好（只有第一次需要按右鍵 →「打開」）。

### 操作方式

| 動作 | 功能 |
|---|---|
| 按住拖曳 | 移動位置 |
| 滑鼠滾輪／觸控板兩指上下滑 | 放大／縮小 |
| 雙擊 | 切換主顯示「5 小時」或「每週」 |
| 游標停在小工具上 | 顯示最後更新時間或錯誤提示 |
| 右鍵（觸控板兩指點一下，或 Control + 點一下） | 選單：調整大小、切換顯示、立即更新、顯示登入網頁、開啟變化紀錄、**登入 Mac 時自動開啟**、離開 |

小女巫不會出現在 Dock 上；要結束請對小女巫按右鍵 →「離開」。

### Mac 常見問題

**Q：雙擊「一鍵啟動.command」出現「無法打開，因為它來自未識別的開發者」？**
這個檔案沒有 Apple 的付費簽章，所以第一次要用「按右鍵 →打開」的方式開啟；或到「系統設定 → 隱私權與安全性」按「強制打開」。只有第一次需要這樣。

**Q：雙擊後顯示「沒有適當的權限」？**
打開「終端機」（在「應用程式 → 工具程式」裡），輸入 `chmod +x `（最後有一個空格），把「一鍵啟動.command」拖進終端機視窗，按 Enter，之後再雙擊一次。

**Q：終端機顯示「下載 Python 失敗」或「下載元件失敗」？**
通常是網路斷線或被公司網路擋住。確認網路正常後，再開一次「一鍵啟動.command」，會從頭再試一次。

**Q：怎麼開啟或取消「登入時自動開啟」？**
對小女巫按右鍵，點「登入 Mac 時自動開啟」，有打勾就是開啟。搬動過資料夾的話，請把它取消再勾一次。

**Q：程式打不開，也沒有任何訊息？**
在 Finder 按 `Command + Shift + G`，輸入 `~/.claude_usage_widget/error.log` 打開錯誤紀錄查看內容。也可以把資料夾裡的 `.venv-mac` 和 `.python-mac` 兩個資料夾丟到垃圾桶，再開一次「一鍵啟動.command」重新安裝（這兩個是隱藏資料夾，在 Finder 按 `Command + Shift + .` 就看得到）。

**Q：怎麼完全移除？**
1. 對小女巫按右鍵，先取消「登入 Mac 時自動開啟」，再按「離開」。
2. 把整個 `ClaudeUsageWidget-mac` 資料夾丟到垃圾桶。
3. 在 Finder 按 `Command + Shift + G`，輸入 `~/.claude_usage_widget`，把這個資料夾（登入狀態與紀錄）丟到垃圾桶。

## 兩個版本都適用的常見問題

**Q：瓶子一直顯示「--」、讀不到數字？**
把游標停在小工具上看提示。通常是還沒登入或登入過期：按右鍵 →「顯示登入網頁」重新登入，登入完關閉視窗。

**Q：瓶子裡沒有顯示重置時間？**
重置時間是從 claude.ai 用量頁面上讀到的。這 5 小時內還沒開始使用、頁面上沒有寫重置時間時，就不會顯示；開始使用後下一次更新就會出現。雙擊切換到「每週」時，下面那一行仍然是 5 小時額度的重置時間。

**Q：在公司網路或開著 VPN 時一直讀不到？**
小工具需要能連到 `claude.ai`。如果公司網路擋住 claude.ai，或需要設定 Proxy 才能上網，小工具也會讀不到；請先確認同一台電腦用一般瀏覽器能打開 claude.ai。電腦睡眠喚醒後，最多等 1 分鐘就會自動恢復更新，也可以按右鍵 →「立即更新」。

**Q：登入視窗裡按「使用 Google 帳號登入」沒反應或被擋？**
Google 不允許在內嵌瀏覽器裡登入。請改用 Email 登入，並把信裡的連結貼到網址列。

**Q：數字跟網頁上的不一樣，或 claude.ai 改版後就讀不到了？**
這個小工具是讀取 claude.ai「設定 → 用量」頁面上的文字，不是官方提供的功能。網頁改版或改成其他語言時可能讀不到或讀錯。可以打開資料資料夾裡的 `last_page.txt` 看看程式實際讀到的頁面內容。

**Q：小工具不見了？**
若拔掉外接螢幕導致位置跑掉，重新開啟時會自動移回主螢幕左上角。若要關閉，對小工具按右鍵 →「離開」。

## 注意事項

- **資料存在哪裡**：所有資料都在你自己電腦的使用者資料夾裡，Windows 是 `%USERPROFILE%\.claude_usage_widget\`，Mac 是 `~/.claude_usage_widget/`（隱藏資料夾）：
  - `web\`：內嵌瀏覽器的登入狀態。**等同你的 Claude 登入資格，不要分享給任何人。**
  - `usage_log.csv`：用量變化紀錄（欄位：時間、5 小時「已使用」%、每週「已使用」%、變化量；記錄的是已使用量，與 claude.ai 網頁上的數字相同），只保留最近 30 天。
  - `last_page.txt`：最近一次讀到的用量頁文字（可能包含你的帳號名稱）。
  - `settings.json`：小工具的位置、大小、顯示模式。
  - `error.log`：錯誤紀錄，超過 200 KB 自動清空。
  - `instance.lock`：防止重複開啟用的小檔案，小工具關閉後可以忽略它。
  - Mac 開啟「登入時自動開啟」時，另外會在 `~/Library/LaunchAgents/com.ty.claude-usage-widget.plist` 建立一個設定檔，取消時會移除。
- **登入資料沒有額外加密**：`web` 資料夾裡的登入狀態由內嵌瀏覽器自行保存，只有你自己的電腦帳號讀得到，但沒有另外加密。不要把這個資料夾複製或傳給別人；不再使用時，照上面「怎麼完全移除」刪掉它即可。
- **會不會傳到網路上**：小工具只會連到 `claude.ai` 讀取你自己的用量頁面，不會把任何資料傳到其他地方。第一次安裝時會從 Python 官方套件庫（PyPI）下載 PySide6 等元件；Windows 版沒有 Python 時還會從 Microsoft（winget）下載 Python，Mac 版會從 GitHub 上的 python-build-standalone 下載免安裝的 Python，並核對檔案指紋（SHA-256）確認沒被竄改。
- **非官方做法**：這是用你自己的登入狀態讀取網頁上顯示的數字，並非 Anthropic 官方提供的功能；網頁改版可能讓它暫時失效。使用前請自行確認是否符合 Claude 的使用條款。為避免對網站造成負擔，更新頻率固定為每 60 秒一次。

## 給開發者（一般使用者不用看）

### 打包成不用安裝 Python 的版本

- **Windows**：先完成「一鍵啟動.bat」的安裝，再雙擊 `build_exe.bat`，完成後在 `dist\ClaudeUsageWidget\` 資料夾裡。
- **Mac**：開啟 `mac/打包成App.command`（會自動下載打包用的 Python 與 PyInstaller），完成後產生 `dist-mac/ClaudeUsageWidget.app` 和 `release/ClaudeUsageWidget-mac-x86_64-v4.10.zip`。
  - 預設打包成 Intel 版（x86_64），Intel Mac 直接執行，M 系列 Mac 透過 Rosetta 2 執行（在 M 系列 Mac 上打包 Intel 版也需要 Rosetta 2）。
  - 想做 M 系列原生版：`ARCH=arm64 bash mac/打包成App.command`。
  - 想做 Intel 與 M 系列都原生執行的通用版：`ARCH=universal2 bash mac/打包成App.command`（需要先安裝 python.org 的 Python 3.12 universal2 版）。
  - 打包好的 App 沒有付費簽章，第一次開啟要按右鍵 →「打開」。

| `dev\template.py` | 主程式的原始模板（圖片以外的程式碼都在這裡；Windows、Mac 共用，Mac 專屬的部分用 `IS_MAC` 分開） |
| `dev\build_assets.py` | 從參考圖切出角色圖片（需要 pillow、numpy、scipy） |
| `dev\build_cry.py` | 從哭哭參考圖切出哭臉圖片（需要 pillow、numpy、scipy） |
| `dev\build_shock.py` | 從驚嚇、害怕、安心參考圖切出臉部圖片與對話框、閃電星、發抖線、汗滴、強調線（需要 pillow、numpy、scipy） |
| `dev\inject.py` | 把切好的圖片嵌入模板，產生 `usage_widget.py`（先跑上面三個） |
| `dev\make_release.py` | 打包下載用的 Windows 與 Mac 兩個 zip |
| `dev\version.txt` | 目前版本號，發佈時使用 |
| `dev\release-notes.md` | 發佈到 GitHub 時顯示的更新說明 |
| `dev\reference\` | 角色參考圖（一般版、哭哭版、驚嚇版、害怕版、安心版） |
| `setup-github.bat`、`save.bat`、`publish-release.bat`、`make-public.bat` | 維護者上傳原始碼與發佈新版用的腳本 |
